# Application experiments

These templates connect source lessons to project-specific tests. They are application hypotheses authored for this fork, not experiments Sakurai ran or evidence that a tactic works in our game. All templates begin `not_run`, with empty observations and no invented success threshold.

Copy a template outside this directory for an actual project. Record the game brief and build/version, the participants' relevant experience, the comparison protocol, and confounders. Change one factor at a time where practical. Ask what improved for the intended audience, what became worse, and whether the source context matched.

Keep source claim IDs and exact source locators. Add actual observations only after testing. Distinguish perceived impact, successful execution, recovery/comprehension, and preference: one does not automatically establish the others. If a tactic failed, record the failure rather than erasing the evidence.

Do not store participant names, recordings, or other sensitive research data in a public repository without authorization. The source library stores design learning; identifiable research belongs in the appropriate private project records.

The templates' `parameters` are null on purpose. Pick values in the prototype and label them project choices. No universal stop duration, shake amplitude, frame-rate target, or difficulty threshold is prescribed here.
