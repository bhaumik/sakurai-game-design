# Rights and provenance boundaries

This repository is a fork of `flossbud/sakurai-game-design`. Preserve its attribution. Its plugin declares `UNLICENSED`, not the public-domain Unlicense, and no inherited root license grants general reuse permissions. This fork does not add a blanket license over inherited materials.

The upstream README describes transcripts captured for private study from the official English on-screen subtitles. They are third-party OCR captures, not an official transcript release. The original subtitles, upstream tooling, upstream analysis, and new fork additions have different authorship and rights considerations.

GitHub distinguishes permission to view and fork a public repository on its platform from broader reuse rights when no license exists. See [GitHub licensing guidance](https://docs.github.com/articles/licensing-a-repository). Forking does not grant authority to relicense the whole collection.

Before a new distribution or licensing claim, clarify permissions with the relevant rights holders. No such contact or permission request has been made in this implementation. Public generated output should favor concise original summaries, brief attributed quotations, and source locators, rather than newly copied full passages. No book content has been imported.

The new paragraph index points to already retained source files and their hashes, rather than duplicating the full transcript corpus. Hashes describe the inherited revision; they do not recover original video/OCR provenance. Curated claims remain clearly labelled according to what was actually checked.
